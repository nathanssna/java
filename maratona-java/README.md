# ☕ Maratona Java - DevDojo

Espaço reservado para organizar e registrar o meu progresso na **Maratona Java Virado no Jiraya** (DevDojo). O objetivo aqui é consolidar a base da linguagem e manter meus códigos e anotações salvos de forma organizada.

---

## Tecnologias e Ferramentas

* **Linguagem:** Java (JDK 17+)
* **IDE:** IntelliJ IDEA / Eclipse / VS Code
* **Ambiente:** Linux (Ubuntu/Debian)

---

## Conteúdos em Estudo

### 1. Sintaxe Básica e Estruturas de Controle
* Tipos primitivos, variáveis e operadores.
* Estruturas condicionais (`if`, `else`, `switch`).
* Estruturas de repetição (`while`, `do-while`, `for`).
* Arrays unidimensionais e multidimensionais.

### 2. Orientação a Objetos (POO)
* Classes, objetos, atributos e métodos.
* Sobrecarga de métodos e construtores.
* Blocos de inicialização.
* Modificadores de acesso e encapsulamento (`private`, `getters/setters`).
* Associação de classes, Herança e Polimorfismo.
* Classes Abstratas, Interfaces e Tratamento de Exceções.

### 3. Classes Utilitárias e Recursos Avançados
* Wrappers e manipulação de Strings.
* Expressões Regulares (Regex) e formatação de datas.
* Coleções (List, Set, Map) e ordenação (`Comparable`/`Comparator`).
* Programação Funcional (Lambdas e Streams API).
